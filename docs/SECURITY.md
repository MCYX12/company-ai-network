# 安全模型

平台的安全目标不是“模型不犯错”，而是即使模型或终端被误导，也不能越权读取资料或伪造身份。

## 身份

- 每个终端使用独立 X.509 客户端证书；证书 CN/SAN 映射唯一 Agent 身份。
- NATS 使用 `verify_and_map`，没有有效证书的连接不能发布或订阅。
- 每个身份有独立的 subject ACL；A 不能读取 B 的回复、任务或心跳。
- 证书可撤销；生产环境应接企业 CA/OCSP，并设置自动续期与到期告警。

## 授权

- 项目、动作、资料范围默认拒绝。
- Router 是授权权威；客户端不能绕过 Router 直接向 Worker 派发。
- 对话、目录、文件、历史分别授权；撤销后旧结果不可再读。
- IAM 依赖不可读时 fail-closed，不会因为读不到名册而放行。
- 人工撤权优先且粘滞，OIDC/目录同步不能覆盖离职状态。

## 模型边界

- 模型只接收已授权资料的分块；提示词不包含未授权文件或聊天原文。
- 模型调用前后重新检查授权；输出经过出口校验。
- 模型失败/超时返回明确错误，不伪造“已完成”。
- 预算、并发和超时可限制资源消耗。

## 审计

- 最小 JSONL 审计记录身份、动作、任务号、状态和结果码。
- 生产环境应把审计锚点外发到独立不可变存储；本地文件不构成 WORM。
- 审计不记录私钥、密码或完整聊天正文。

## 密钥与运行目录

- `.runtime*` 包含证书、私钥、账本和日志，已加入 `.gitignore`。
- 测试 CA 仅用于本地；默认 7 天有效，不要分发给生产终端。
- 生产私钥应放在所有者独占目录或 HSM；不要通过 Git、聊天或工单传递。
- 发布包不包含企业 CA 私钥、业务资料或真实模型权重。

## 威胁模型（摘要）

| 威胁 | 缓解 |
|---|---|
| 伪造终端身份 | mTLS + 证书映射 + CA 校验 |
| 横向读取其他项目 | 项目范围 + subject ACL + Router 拒绝 |
| 重放旧请求 | 短期去重 + 任务幂等键 |
| 模型提示词注入 | 结构化动作 + 输出校验 + 工具/范围限制 |
| 撤销后继续读取 | 每次读取重检授权；旧结果按范围隐藏 |
| 审计被本地篡改 | 生产外发独立锚点；本地仅作最小记录 |
| 依赖/制品被替换 | 版本锁定 + SHA256 + 发布门禁 |

## 已知限制

- 单机 PoC 不等于企业生产安全认证。
- 测试 CA、回环监听和演示身份不能直接用于生产。
- 真实 IdP、VLAN/ACL、WORM、异地 DR 和容量验收需要现场完成。
