# 剩余工作

平台已具备可运行的工程基线；以下事项必须在真实企业环境完成，不能由本机测试或历史记录代替。

## 生产准入前置

| 编号 | 事项 | 需要的现场证据 |
|---|---|---|
| E-01 | 企业 IdP / 员工入转离 | 真实 OIDC 租户、claim/subject 映射、离职撤权 |
| E-02 | 物理 HA | 三个故障域、双 Router、共享权威存储、分区演练 |
| E-03 | 离线模型 | 真实内网模型/权重、断公网冷启动、模型质量 |
| E-04 | 项目与质量 | 真实项目/负责人、资料授权、独立业务验收 |
| E-05 | 网络 | 真实 VLAN/ACL/DNS/稳定地址与证书/SAN |
| E-06 | 终端矩阵 | 企业终端型号、客户端服务身份、组织签章 |
| E-07 | 容量 | 真实业务形状 100 QPS / 1800 秒、P95/成功率 |
| E-08 | 值班告警 | 真实通道、独立回执、升级闭环 |
| E-09 | 审计 | 独立不可变 WORM、保留期限与责任人 |
| E-10 | 灾备 | 加密异地全量恢复、真实 RTO/RPO |
| E-11 | 员工试点 | 50–200 人试点与反馈闭环 |
| E-12 | 制度 | SLO、权限、期限、责任和正式发行身份 |

## 工程侧可继续做

- 真实 AgentScope/MAF 客户端的 A2A 联调与限流。
- 审计锚点外发到远端/WORM 的适配器。
- 端到端容量压测脚本与故障注入矩阵。
- Windows 客户端签名、自动升级与终端矩阵自动化。
- 文档与部署脚本的持续可重复验证。

## 不建议

- 在没有现场证据时把测试通过写成“生产就绪”。
- 把测试 CA、私钥或业务资料提交到仓库。
- 用模型输出替代授权、审计或人工确认。
