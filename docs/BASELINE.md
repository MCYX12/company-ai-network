# 当前基线

## 定位

企业内网 Agent 协作平台的可运行 PoC/受控试用基线。首条业务是“员工跨电脑询问获准项目的进展与当前工作”，所有动作只读。

## 已实现

| 领域 | 能力 |
|---|---|
| 传输 | NATS 2.11.9、mTLS、subject ACL、自动重连、短期重放拒绝 |
| 身份 | 证书映射、独立身份、管理员/成员、证书签发与撤销 |
| 授权 | 项目/动作/资料范围默认拒绝；对话、目录、文件、历史分开授权 |
| IAM | OIDC/JWT + JWKS、在职名册、人工撤权、fail-closed |
| 任务 | 持久账本、幂等、outbox、重试、死信、租约/fencing、JetStream |
| 业务 | `get_status`、`get_project_progress`、受控 `ask_peer` |
| 资料 | 分块、来源/快照、新鲜度、引用边界、导出范围 |
| 终端 | Linux CLI/控制台、Windows V43、受限反向转发 |
| 运维 | 健康检查、告警落盘、审计、备份/恢复、灾备演练 |
| 发布 | 双 CI、SHA256、内容摘要、公开源门禁 |

## 兼容性

- Python 3.11+
- NATS Server 2.11.9
- Linux / Windows；macOS 端本轮冻结
- 单机 PoC 默认 `tls://127.0.0.1:14222`

## 非目标

- 通用远程执行、任意 Shell、任意文件读取。
- 公网 SaaS 或多租户门户。
- 未经现场验收即宣称企业生产就绪。

## 证据等级

设计 / 已实现 / 隔离验证 / 实机验证 / 现场验收。仓库中的通过记录不自动提升等级；生产准入需要现场证据和签字。
